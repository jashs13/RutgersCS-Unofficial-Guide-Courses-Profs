SECTION 1 — OFFICIAL COURSE DESCRIPTION (from cs.rutgers.edu)
================================================================

Much of the world's data resides in databases. The purpose of this course is to introduce
relational and NoSQL database concepts with emphasis on both theoretical and practical
learning. This course helps students learn and apply knowledge of the SQL language and
implementing components of relational and NoSQL database systems (DBMS). Students will
create database instances in the cloud for both relational and NoSQL database systems such
as MySQL, SQL Server, Amazon Redshift, Google BigQuery and MongoDB. Through a couple of
hands-on projects students will practice building and running advanced SQL scripts and
Python/Java code.

SECTION 3 — COURSE TOPIC BREAKDOWN (from official syllabus)
================================================================

Part I — Basics (Weeks 1–4)
  - Database system design, ER Diagrams, Relational Model
  - SQL: Building and querying a relational database
  - Advanced SQL

Part II — Applications (Weeks 5–6)
  - Backend: AWS, JDBC, Java Servlets
  - Frontend: JavaScript, JSON, HTML, CSS

Part III — NoSQL Databases (Weeks 7–9)
  - Key-Value Stores (Amazon Dynamo)
  - Column-Oriented DBs (Google BigTable)
  - Document DBs (Apache CouchDB, MongoDB)

Part IV — Storage & Efficiency (Weeks 10–11)
  - Storage, Indexing, Query Evaluation
  - Writing efficient queries

Part V — Databases in Real Life (Weeks 12–14)
  - Partitioning, cloud storage, pricing models
  - Data Cleansing
  - Data Warehousing

SECTION 7 — TIPS & SURVIVAL NOTES
================================================================

- First-year MS friendly — no DB prerequisites required
- Two projects run all semester — start early, don't treat them as one-off assignments
- Project 1 is a full web app with a database backend — expect to use AWS + SQL + a web framework
- Project 2 involves real large data + MongoDB — useful hands-on experience for data engineering roles
- SQL is heavily tested in exams — practice writing complex queries before the midterm
- NoSQL section (MongoDB, BigTable, Dynamo) is industry-relevant and worth taking seriously
- Pairs naturally with CS543 (Massive Data Storage) — together they cover the full data pipeline
- Good course for Massive Data Analytics concentration students (required track course)
