SECTION 1 — OFFICIAL COURSE DESCRIPTION (from cs.rutgers.edu)
================================================================

In today's world of massive amounts of data, new methods and techniques are needed to dive
deeper into such data including hands-on practical work on real data sets. This course covers
the major existing algorithmic primitives necessary for the processing of "massive" data sets
in external memory and data streaming settings. It also introduces various deep learning
frameworks and corresponding neural methods in a variety of application areas. Students have
the opportunity to gain experience with major platforms for storage and retrieval, including
Hadoop Distributed File Systems and Data Streaming with Apache Spark. The focus of one
"large data" project is on techniques for information retrieval, natural language processing,
and the necessary indexing methods for the retrieval of semantically relevant information.
A second "large data" project focuses on the application of a deep learning framework to an
application area of each student's choice.

================================================================
SECTION 3 — COURSE MODULE BREAKDOWN (from official syllabus)
================================================================

Module 1: Introduction to Massive Computing, MapReduce, Hadoop HDFS
Module 2: Streaming Data & Apache Spark; NLP pipeline examples
Module 3: Clustering and PageRank
Module 4: External Memory Algorithms
Module 5: Search & Storage — Inverted Indexes, ElasticSearch, Semantic Hashing, Vector Representations
Module 6: Similarity Search, LSH (Locality Sensitive Hashing), Spatial Indexing
Module 7: Deep Learning Principles — Gradient Descent, Backprop, Feedforward Networks, Activation Functions, Softmax
Module 8: Deep Learning for Classification, Retrieval, and Labeling — CNNs for sentiment analysis,
          text classification, neural IR, named entity recognition
Module 9 (Selected Topics):
  a. Language Models, RNNs, LSTMs, Seq2Seq
  b. Semantic Analysis, Attention, Neural Machine Translation
  c. Question Answering and Structured Data
  d. Graph Streaming Algorithms

SECTION 7 — TIPS & SURVIVAL NOTES
================================================================

- Fall only — plan your MS schedule accordingly; missing it means waiting a full year
- Two large projects are the core of the course — one on IR/NLP with Spark, one on deep learning of your choice
- The deep learning project is open-ended — choose an area you care about and it becomes a portfolio piece
- Module 5 (vector representations, semantic hashing, ElasticSearch) is directly relevant to RAG systems
  and modern ML engineering roles — pay close attention here
- Spark setup can be painful — start the environment setup in Week 1, not Week 3
- Strongly recommended to take CS527 (databases) before this course — it's listed as a prerequisite
- Good GPU access tip: Rutgers provides OARC (Office of Advanced Research Computing) cluster access —
  apply early in the semester for project compute resources
- Pairs naturally with CS527 (prerequisite) and CS536 (ML) for a complete data + ML stack
